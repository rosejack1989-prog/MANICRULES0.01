Release Theta 3.2

Pattern Studio DAW

The local Pattern Studio contains 500 preloaded progressions and exercises spanning all 12 keys, drawn from 42 musical forms built with the bundled interval, chord and scale catalogs. The library and audio engine run without a network connection after the app cache is ready.

  1. Choose a preloaded pattern, search by name, and tap Load. Set the key and tempo for the arrangement.
  2. To write your own, choose a chord, scale or interval, select its catalog reference, choose a root degree and bar length, then tap Add to arrangement.
  3. Move blocks up or down, remove them, and combine any source types in one sequence. Play starts local synthesis; Stop cancels scheduled notes.
  4. Name a pattern and save it to this browser. Open or delete saved patterns in the On this device section.
  5. Export All MIDI (ZIP) packages individual files for the 500-pattern library, saved patterns and the current arrangement, plus one compiled MIDI with section markers. This uses the bundled ZIP library and works offline.

Saved patterns stay in this browser profile on this device. Use the app backup tools before changing devices; the DAW does not send patterns to a server.

Design

The desktop header uses a compact row of familiar icons and a dedicated Play control to keep core actions visible without crowding the fretboard. Each icon has an accessible name and a tooltip. On phones, Menu expands the same destinations with text labels and touch-sized targets.

Page layouts follow their task: explorers prioritize filters and results, lessons and eBooks prioritize reading, practice pages prioritize controls, and data pages preserve wide tables through horizontal scrolling. Mobile View is an opt-in preview for the current tab; fresh tabs start in Desktop View. Narrow screens still receive responsive layouts automatically.

Icons, styles, scripts, data and audio are local project assets. No icon font, remote font or CDN is required.

How To

  1. For PWA offline use, open a root app page over HTTPS while online and wait for the offline-ready notice. To make an archive, use Home or Release Notes → Download Offline ZIP only after the cache is ready.
  2. To use the ZIP on a computer or Android browser that permits local HTML scripts, extract the full folder tree and open index.html. Keep all files together; the package includes OFFLINE-START-HERE.txt.
  3. Use the header icons on desktop. On a phone, tap Menu to reveal named links. Tap an icon or its label to open that section.
  4. Open the Fretboard from Home, choose a key and pattern, then use the header Play or Stop controls. In the scale, chord and interval explorers, Hear plays the selected catalog item on that page; Fretboard opens its diagram.
  5. Open Pattern Studio from the global DAW link or Home. Search and load one of 500 patterns, or choose an interval, chord or scale block, set its root and length, then add and arrange it. Set key and BPM, tap Play or Stop, and save named patterns to this device.
  6. In the Scales and Chords explorers, search or filter, then Hear plays on the current page, mark a favorite or open Fretboard. Intervals can be filtered by related chords and scales.
  7. Use the Mobile View switch to preview the compact layout on a wide screen. The choice carries between pages in the same tab; a new tab starts in Desktop View.
  8. Use Settings to export a backup before moving devices or clearing browser data. Favorites, progress and notes stay in this browser.

FAQ

Does the app need the internet?

The hosted app needs a first online visit to install its full cache and needs a connection for later updates. After the offline-ready notice, cached pages, data, audio, study content and export libraries work offline. The ZIP packages the same precached files.

What is in the Offline ZIP?

Every file in the service worker precache, plus an offline start guide. Download it after the cache-ready notice. Extract it without changing the folder structure. Local-file execution depends on the browser.

What is Pattern Studio?

A local DAW-style arranger with 500 preloaded chord progressions, scale studies, interval exercises and mixed patterns. Build a custom sequence from the bundled theory catalogs; playback is synthesized on this device.

Are my DAW patterns synced?

No. Saved arrangements are stored in this browser profile on this device. They do not upload or sync; use browser backup practices before changing devices.

Where does the app open?

Home opens by default, including when you launch the installed app. Choose Fretboard to open the interactive instrument.

Do explorer Hear buttons leave the page?

No. Scales, chords and intervals play through the bundled synthesizer on their current page. Allow audio after a tap or click.

What does Base 0 mean?

It numbers pitch classes C=0, C-sharp/D-flat=1, through B=11. Numbers wrap at the octave; a chord or scale shows its distinct pitch classes from the root.

Why is a new tab in Desktop View?

That is the default. An explicit Mobile View selection lasts for the current tab and follows its page navigation.

Where is my saved data?

In local browser storage on this device. Use Settings backup and restore to move it; private browsing or clearing site data may remove it.

Can I export while offline?

Yes. Export libraries are bundled locally and files are generated on the device.

Can I play and stop from the fretboard header?

Yes. Select a scale, chord, interval or custom pattern and tap Play. Stop cancels the remaining sequence and releases active voices.

How many study resources are included?

The Theory Cards deck has 612 cards, and the eBook page offers 100 locally generated PDF guides.

Why might sound be muted on iPhone?

Start playback with a tap, raise media volume and check the hardware silent switch. Browsers require a user gesture before audio starts.

Troubleshooting

  • Run the audit: open Fretboard → Sidebar → Quick Actions → Run App Checks. Run it after the offline-ready notice so cache checks reflect a complete install.
  • No offline-ready notice or ZIP error: use the hosted HTTPS app, reconnect, reload Home and wait for the cache installation. Private browsing, denied storage or low device space can prevent it.
  • ZIP will not open as an app on iPhone: use Safari → Share → Add to Home Screen while online, open that installed app once until offline-ready, then launch it offline. iOS Files previews and local-file script restrictions vary; the ZIP is an archive, not an iOS app installer. For iPhone offline use, install the hosted app from Safari Home Screen while online, then open it once to finish caching.
  • An old version opens: reconnect and reload once so the updated service worker can install the new cache; then reopen the app.
  • No sound: tap Hear or Play directly in the page, check media volume and the iPhone silent switch, then retry. If audio was interrupted by switching apps, tap playback again to resume the audio context.
  • Pattern Studio says a reference is unavailable: reload the hosted app while online so the bundled theory catalog cache completes, then reopen DAW.
  • Progress or favorites disappeared: check that you are in the same browser profile and have not cleared site data. Restore a Settings backup if available.
  • A table is wider than the screen: swipe horizontally within the table; values are kept readable rather than compressed.
  • Installing on a phone: use Samsung Internet's Install/Add to Home Screen option or Safari's Share → Add to Home Screen. Serve over HTTPS; file:// pages cannot install the service worker.

Offline & installation

  • Open a root app page over HTTPS while online and wait for "ready to work offline". The worker installs every listed local app asset before it marks the cache ready.
  • Use Download Offline ZIP to save those cached files in their original folder structure. On a computer or Android browser supporting local HTML scripts, extract the archive and open index.html; file:// pages cannot install a service worker, so updates and PWA storage are unavailable there.
  • For iPhone, install the hosted HTTPS site from Safari using Share → Add to Home Screen while online, then open it once to finish caching. Safari local-file policies mean an extracted ZIP is not guaranteed to run from Files.
  • The Release Notes indicator shows online/offline state and whether this version’s cache marker is installed. The DAW, its 500 generated presets and its synthesizer are included in the same local cache.
  • Install it with your browser's Install app or Add to Home Screen option to launch it like a native app.
  • Updates download when you are online and apply through the service worker. Offline use requires completing the current version's install first.
  • Responsive layouts are provided for phones, but physical Samsung/iPhone and airplane-mode testing was not available for this release. Browser/OS policies, storage settings and audio routing can vary.
  • Everything you save stays in this browser. Use Settings → Backup to keep a copy or move to another device.

Known limitations

  • Offline use needs one online visit over http(s). Opening the files directly from disk (file://) works, but cannot be cached for offline use or installed.
  • Data is stored per browser and per device; clearing site data deletes favourites, progress, notes and presets. There are no accounts or cloud sync - use Backup/Restore.
  • Spelling never uses double accidentals or Cb/Fb/E#/B#: F# major shows F for E#, and C diminished 7 shows A for Bbb.
  • Many catalogue scales are identified by their interval formula rather than a traditional name.
  • Browsers only allow sound after a tap or click, so links that "play" a pattern wait for your first tap. On iPhone the silent switch mutes the app.
  • Very large batch exports (every scale as Word/ZIP) can take minutes and may run out of memory on phones.
  • PDF text uses standard fonts, so symbols appear as b and # rather than musical flat/sharp glyphs.
  • There is no MIDI input, recording or notation view. MIDI export is output-only.
  • Quiz questions are generated at random; scores are kept locally and are not verified by a server.
